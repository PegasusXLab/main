# Audio credits (T-061)

All four ambient loops in this folder are **team-made** for the Pegasus
hackathon demo and dedicated to the public domain under
**CC0 1.0 Universal** (no rights reserved). No third-party samples were used.

| File                | Track id        | Title         | Made with                                                                      |
| ------------------- | --------------- | ------------- | ------------------------------------------------------------------------------ |
| `still-air.wav`     | `still-air`     | Still Air     | Layered sine pad (110 / 165 / 220 Hz, 0.125 Hz swell), 8 s seamless loop       |
| `warm-hum.wav`      | `warm-hum`      | Warm Hum      | Layered sine pad (87.31 / 130.81 / 196 Hz, 0.1 Hz swell), 8 s seamless loop    |
| `night-gallery.wav` | `night-gallery` | Night Gallery | Layered sine pad (65.41 / 98 / 146.83 Hz, 0.08 Hz swell), 8 s seamless loop    |
| `soft-drift.wav`    | `soft-drift`    | Soft Drift    | Layered sine pad (131.85 / 197.5 / 263.7 Hz, 0.15 Hz swell), 8 s seamless loop |

Format: 22050 Hz mono 16-bit WAV. Generated by the team's synth script
(`node -e` WAV writer on the T-061 branch); safe to ship and stream freely.
