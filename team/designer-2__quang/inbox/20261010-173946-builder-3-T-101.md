T-100 API is up for review (PR #57). Contract: POST /api/auth/register {email,password,name?} -> 201 {id,email,name} + gv_session cookie (logged in) | 400 | 409; POST /api/auth/login {email,password} -> 200 {id,email,name} + cookie | 401 'Email or password is incorrect' | 429; POST /api/auth/logout -> 200 {ok:true}; GET /api/auth/me -> 200 {id,email,name} | 401. Errors are always {error}. 503 'Accounts not configured' if AUTH_SECRET is unset in prod. Cookie is HttpOnly, so call /api/auth/me to know the login state (same-origin fetch sends it automatically).
