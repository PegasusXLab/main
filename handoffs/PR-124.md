## Builder notes
### What changed
Gallery-level artist profile (name, bio, up to 8 https links, auto-labeled by platform), shown as a "by <name>" chip in the tour header that opens a glass profile panel. Inspectable pieces can pick an action for their link (Buy, Listen, Pre-save, Watch, Book, Tip, or Learn more) plus an optional price; anything but Learn more is the inspect panel's main button ("Buy · $40"). Links only, no payments, no new deps.
### How to test
1. Editor → Gallery Properties → Artist profile: enter a name, a bio, and links like `open.spotify.com/artist/…` and `instagram.com/you`. Each shows "Shows as Spotify" / "Instagram"; `http://…` shows an error and isn't saved.
2. Add a Picture, keep Inspectable on, set Link = a Spotify album, Button = Pre-save, Price blank. Save.
3. Publish and open `/g/<id>`: the "by <name>" chip sits next to the title. Click it: the profile panel shows the bio and labeled links. Esc closes it.
4. Click the picture: the panel shows a white "Pre-save" button (open.spotify.com) that opens in a new tab.
