### What changed

Landing page for new visitors plus deep-linkable `/register` and `/login`, rebuilt from
Quang's `galleriverse-ui-design` reference on the merged T-110 tokens and T-111 primitives
(not copied wholesale). Wired to the live T-100 auth API.

- `src/app/page.tsx` — landing composition: header (brand + session-aware right side),
  hanging-wall `Showcase`, `Hero` (pitch + auth panel / "Create a gallery" when signed in),
  templates cards, "Open edit link" form. Preserves every existing start-screen string and
  the `edit-link` / `edit-link-error` ids (unit test asserts them).
- `src/app/login/page.tsx`, `src/app/register/page.tsx` — thin pages (metadata + `AuthPage`).
- `src/components/auth/*` — `authClient` (register/login/logout/me against the T-100
  contract; inline 401/409/429/503 mapping), `AuthForm` (client validation, pending state,
  server errors, success → new blank gallery at `/edit/local`), `UserMenu`, `AuthPage`.
- `src/components/landing/*` — `Hero` (toggle "New here / Returning"; swapped for a
  "Create a gallery" card when signed in), `Showcase` (auto-advancing hanging wall; respects
  `prefers-reduced-motion` via `useSyncExternalStore`; keyboard + arrow buttons), `startGallery`.
- Logged-in state read from `GET /api/auth/me` (HttpOnly cookie). Header shows name/email +
  "Log out" via `UserMenu`.
- Added `lucide-react` (approved by Quang). No other dependency changes.
