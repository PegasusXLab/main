### What changed
1. **Curated ElevenLabs Docent Voice Personas (`src/lib/elevenlabs/voices.ts`)**:
   - 5 curated docents: Marcus (Art Historian), Rachel (Warm & Insightful), Antoni (Deep & Contemplative), Bella (Vibrant & Energetic), Liam (Measured & Scholarly).
   - Support for custom voice IDs.
2. **Server-Side ElevenLabs Speech Synthesis (`src/app/api/narration/generate/route.ts`)**:
   - Synthesizes speech using model `eleven_turbo_v2_5`.
   - Saves resulting MP3 blob directly to cloud/local storage using standard `storage.putObject`.
   - Returns permanent public URL.
   - Includes graceful deterministic offline mock fallback when `ELEVENLABS_API_KEY` is not configured.
3. **In-Browser Microphone Voice Recording (`src/lib/audioRecorder.ts`)**:
   - Clean native `MediaRecorder` hook/utility for room creators.
   - Includes custom `audioBufferToWav` 16-bit PCM RIFF WAVE encoder ensuring valid audio magic bytes across all browsers.
4. **Global Narration State & "First-Time Only" Tracking (`src/audio/narrationStore.ts`)**:
   - Plays automatically the first time a user visits a room or inspects an item/artwork (`visitedRoomIds`, `visitedItemIds`).
   - Persists user preferences (`gv:audioguide:muted`).
   - Tracks audio duration, current time, play/pause state.
5. **Dynamic Audio Ducking (`src/audio/RoomAudio.tsx`)**:
   - When room narration or item voiceover starts, background room music smoothly ducks down to ~22% (`volume * 0.22`).
   - Restores smoothly to 100% when narration finishes or is paused/cancelled.
6. **Unified Voiceover Editor Control (`src/panels/VoiceoverControl.tsx`)**:
   - Three tabs: **ElevenLabs AI**, **Record Mic**, **Upload Audio**.
   - Integrated into `RoomPanel.tsx`, `ObjectPanel.tsx` (wall artwork), and `FloorObjectPanel.tsx` (3D models & cutouts).
   - "Use description as script" button to quickly draft docent script from existing artwork metadata.
7. **Viewer Audio Guide HUD & Plaque Integration (`src/viewer3d/AudioGuideHUD.tsx`, `src/viewer3d/Plaque.tsx`, `src/viewer3d/TourView.tsx`)**:
   - Top floating viewer HUD displaying active docent voice, live equalizer wave animation, and one-click global audio guide toggle.
   - Plaque modal auto-narrates on first open and provides interactive "Listen to Docent" player button.

### How to test
1. Run `npm test` - all 794 unit tests across 107 suites pass green.
2. Open editor at `http://localhost:3000/editor`:
   - Click a room -> open Voiceover panel.
   - Select an ElevenLabs voice persona (e.g., Marcus), type a narration script, and click "Generate with ElevenLabs".
   - Or click "Record Mic" to record audio directly.
   - Switch to 3D Tour view: narration triggers automatically on first room arrival, and background music ducks down cleanly.
3. Inspect an artwork: plaque opens with audio guide controls and automatically narrates.
