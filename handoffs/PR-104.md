## Builder notes
### What changed
Re-lands the editor live 3D preview, split view, gallery overview and room back link that #101 reverted, with the root-cause fix for the React #185 production crash.

**Root cause:** `GalleryPanel` used `useGalleryStore((s) => s.gallery.objects ?? [])`. A gallery without an `objects` key gets a new `[]` on every snapshot, so `useSyncExternalStore` loops. The fix is the exported `selectObjects` selector with a stable empty array.

Changed from #100: `Live3DPreview` starts collapsed (opened on demand) and is hidden below `md`. Expanded by default, it covered rooms at 1280 px and broke `editor.spec.ts`, and it kept a second WebGL canvas running during 2D editing. `AddMenu` moved to `z-30`.

The inertial camera from #100 is NOT included; it is a separate re-land (see `handoffs/OPUS-5.5-HANDOFF.md`).
