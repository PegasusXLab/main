## Builder notes
### What changed
Objects can carry a device drawn in code on top of CC0 host furniture: a video screen (media cabinet), a listening station (console; the chosen song takes over the room's music, the record spins while audible), and a guestbook (side table; signatures via a new API, shown in the panel and on the book's pages). Artworks can carry a song (album wall). Inspect panels get Share, and `?piece=<id>` deep-links. The editor gets + Add → Video screen / Listening station / Guestbook and an Interactive section. 4 new library hosts. `npm run seed:showcase` publishes the 5-room "Midnight Static" showcase.
### How to test
1. `npm run dev`, then `npm run seed:showcase` (add `--voices` if ELEVENLABS_API_KEY is set). Open the printed View link.
2. Walk the rooms. Screening Room: click the TV, then *Turn sound on* (the music pill steps aside). Listening Room: click the turntable, play a record (the music pill shows it, the record spins). Album Wall: open a cover, play its song, see *Buy · $1*. Influences: sign the guestbook, close, reopen (your note is listed; the pages update).
3. Share in any panel copies `…?piece=<id>`; opening it lands on that piece.
4. Open the Edit link: + Add → Listening station, then add a song (MP3) in the Interactive section; it appears in the 3D preview.
