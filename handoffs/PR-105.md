## Root cause of the #185 prod crash
`GalleryPanel` used `useGalleryStore((s) => s.gallery.objects ?? [])`, which returns a new array every render when `objects` is undefined, so zustand loops into "Maximum update depth exceeded". Fixed with a stable module-level empty array.
