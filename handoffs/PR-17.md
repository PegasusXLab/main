# Handoff: PR-17 / T-031
## Builder notes
### What changed
- **Edit Key Module:** `src/lib/server/editKey.ts` provides random edit key generation, scrypt hashing (`<salt>:<hash>`), and constant-time key verification via `crypto.timingSafeEqual`.
- **POST `/api/galleries`:** Validates document against `validate()`, rejects `data:` image URLs (ADR-009), assigns a server id via `nanoid()`, timestamps, generates edit key and hashes it, stores the JSON and key hash privately via `Storage`, and returns `{ id, editKey, viewUrl, editUrl }` (status 201).
- **GET `/api/galleries/[id]`:** Returns stored Gallery JSON with Content-Type `application/json` (status 200) or 404 if missing. Never returns or exposes the key hash.
- **PUT `/api/galleries/[id]`:** Requires `x-edit-key` header, validates against stored hash using constant-time comparison (403 on mismatch/missing), runs `validate()`, rejects image data URLs, preserves gallery id, bumps `updatedAt`, and persists JSON (status 200).
- **Payload limits:** Enforces 1 MB request body limit returning 413.
- **Tests:** 10 new tests in `editKey.test.ts` and `route.test.ts` covering key generation, hashing, timing safe comparison, full create -> read -> update lifecycle, 403 on invalid key, 400 on invalid body/image data, 404 on missing, and 413 on payload limit.
